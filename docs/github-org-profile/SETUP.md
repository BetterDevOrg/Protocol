# Copy this folder to the BetterDevOrg/.github repository

GitHub displays organization profile READMEs from:

```text
BetterDevOrg/.github/profile/README.md
```

## Setup

1. Create a new public repository: **BetterDevOrg/.github**
2. Copy `profile/README.md` from this folder into that repo at the same path
3. Commit and push — the README appears on https://github.com/BetterDevOrg

Pin **protocol** under org Settings → pinned repositories.
