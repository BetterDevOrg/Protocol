# BetterDev

**Chain-agnostic reputation and coordination for real-world engineering communities.**

BetterDev helps engineers prove participation, build portable reputation, and connect through curated local meetups — starting on Arbitrum Sepolia.

🌐 **Live:** [betterdev.live](https://betterdev.live)  
📦 **Protocol:** [github.com/BetterDevOrg/protocol](https://github.com/BetterDevOrg/protocol)

---

## What we build

- **Community ID** — universal member identity
- **BetterDev Passport** — on-chain credential and reputation
- **Meetup verification** — verified attendance and reputation events
- **Builder Circles** — fair group coordination (Chainlink VRF)
